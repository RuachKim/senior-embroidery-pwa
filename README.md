# 🧵 쉬운 자수 만들기 (Senior Embroidery PWA)

디지털 기기 및 복잡한 소프트웨어 조작이 서툰 고령층(시니어) 사용자들을 위해 특별히 제작된 **초간편 휴대용 자수 변환 소프트웨어**입니다. 어르신들이 스마트폰으로 직접 찍은 손그림이나 글씨 사진을 손쉽게 자수기 전용 파일(`.PES`, `.DST`, `.JEF`)로 변환(디지타이징)할 수 있습니다.

## 🌟 주요 기능 (Features)
- **시니어 특화 UX/UI**: 시원하게 커진 글씨와 버튼, 헷갈리지 않는 직관적인 3단계 프로세스를 제공합니다.
- **비전 기반 자동 윤곽선 추출**: 복잡한 설정 없이도 그림의 외곽선을 자동으로 인식해 자수 스티치 경로로 변환합니다.
- **완벽한 오프라인 구동 (PWA)**: 파이썬 환경임에도 서버 없이 브라우저 내부에서 작동합니다(WebAssembly/Stlite 활용). 앱을 설치하면 인터넷이 없는 환경에서도 항상 구동됩니다.
- **다양한 자수기 호환**: 브라더(`.PES`), 타지마(`.DST`), 자노메(`.JEF`) 등 가정용 및 공업용 주요 포맷을 모두 지원합니다.
- **안내 음성 (TTS)**: 필요 시 각 단계에 대한 안내 음성을 재생할 수 있는 옵션을 지원합니다.

## 🚀 사용 방법 (How to Use)
웹사이트 주소에 접속하거나, 스마트폰/태블릿 브라우저 메뉴의 **"홈 화면에 추가(Install App)"**를 선택하여 기기에 앱처럼 설치한 뒤 사용할 수 있습니다.

1. **사진 올리기**: 자수로 만들고 싶은 그림이나 글씨를 업로드합니다.
2. **설정하기**: 원하는 자수의 크기(가로/세로 mm)와 사용하시는 자수기 브랜드를 선택합니다.
3. **만들기 및 저장하기**: 버튼을 누르고 잠시 대기한 후, 완성된 자수 파일을 저장합니다.

## 🛠 기술 스택 (Tech Stack)
- **Frontend & App Logic**: Python 3, [Streamlit](https://streamlit.io/)
- **Core Processing**: `pyembroidery` (자수 경로 생성), `OpenCV-Python` (이미지 윤곽선 처리), `Pillow` (이미지 처리)
- **Deployment Architecture**: [Stlite](https://github.com/whitphx/stlite) (WebAssembly 파이썬 런타임), Progressive Web App (PWA)

## 📌 배포 환경
이 레포지토리는 백엔드 서버 없이 브라우저에서 실행되는 완전한 정적 사이트(Static Site)입니다. GitHub Pages를 통해 배포하여 누구나 쉽게 접속할 수 있습니다.
